# StegoDetector
StegoDetector — программное обеспечение для обнаружения факта сокрытия информации в цифровых стеганографических контейнерах.
**О проекте**
Программа использует методы стегоанализа для исследования характеристик анализируемых файлов, выявления статистических отклонений и определения потенциального наличия скрытых данных.
Основные возможности
-Загрузка цифровых файлов для проведения анализа;
-Исследование статистических характеристик файлов;
-Выявление признаков возможного использования стеганографии;
-Применение алгоритмов стегоанализа;
-Формирование результатов проведённого анализа;
-Отображение заключения о вероятности наличия скрытой информации.
**Методы анализа**
LSB-анализ;
Анализ гистограмм;
Статистический анализ распределения данных;
χ²-анализ;
RS-анализ.
**Ограничения**
Результаты анализа отражают наличие или отсутствие признаков, характерных для определённых методов стеганографии.
Отсутствие выявленных аномалий не гарантирует отсутствия скрытой информации. Обнаружение статистических отклонений также не является безусловным доказательством применения стеганографии.
